# example-lens-active-inference

**Install:** copy the install link from [reefchat.io/plugins/example-lens-active-inference](https://reefchat.io/plugins/example-lens-active-inference), then in Reef go to **Settings → Plugins → Install plugin** → Remote → paste the Git URL → **Fetch and review** → **Install**.

For self-hosting or local archives, see [plugin examples](../README.md).
