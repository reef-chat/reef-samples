# example-profile-research

**Install:** copy the install link from [reefchat.io/plugins/example-profile-research](https://reefchat.io/plugins/example-profile-research), then in Reef go to **Settings → Plugins → Install plugin** → Remote → paste the Git URL → **Fetch and review** → **Install**.

For self-hosting or local archives, see [plugin examples](../README.md).
